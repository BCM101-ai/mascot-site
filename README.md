# Mascot — website

The homepage and privacy policy for [Mascot](https://github.com/BCM101-ai/mascot),
a macOS desktop companion that tracks coursework deadlines.

Served by GitHub Pages. The app itself lives in a separate private repository;
released builds are attached to this repo so the download link works publicly.

Source of truth for these pages is `Website/` in the app repo — edit there and
run `Scripts/sync-site.sh` to publish.
